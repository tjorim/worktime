# Bootstrap removal (#1384)

Final step of the Tailwind + Base UI migration (#1376). Bootstrap, react-bootstrap, Bootstrap Icons and
Sass are gone, together with the `tw:` prefix, the `legacy` cascade layer and both lint baselines. The
per-area notes (`shared-controls-`, `settings-`, `wizard-`, ... `-migration.md`) describe the staged
steps that led here and still mention the scaffolding that this change deleted.

## What was removed

- Packages: `bootstrap`, `bootstrap-icons`, `react-bootstrap` (and with them their transitive
  dependencies), plus the now unused `sass` and `postcss-selector-parser` dev dependencies.
- Styles: `main.scss`, `_legacy.scss`, `_utilities.scss`, `_shifts.scss`, `_variables.scss`,
  `_calendar.scss` and the Bootstrap Sass configuration. `legacy-classes.json`,
  `legacy-inline-styles.json`, their generator and the drift check in `pnpm lint` are deleted; the
  lint config has no allow-lists or per-file overrides.
- `tw:` prefix: removed from both Tailwind imports, `components.json` and `@/lib/utils` (every
  utility in `src/`, `tests/` and `e2e/` converted in one pass; no `tw:` remains).
- Bootstrap-only tests (`tailwind-coexistence.test.ts`, `tailwind-coexistence.spec.ts`) are replaced by
  `tests/lib/styleStack.test.ts` and `e2e/theme-tokens.spec.ts`.
- Dead rules that matched no markup: `.btn`/`.card`/`.nav-link`/`.form-*` motion rules, dark `.card`
  elevation, `.install-prompt`, `.connection-*`, `.loading`, `.container-fluid` mobile padding,
  `.month-calendar-day.is-long-weekend/.is-bridge-day` and `.month-calendar-event-empty`.

## What replaced it

| Before | After |
| --- | --- |
| `[data-bs-theme]` on `<html>` | `[data-theme]` on `<html>`, set by `App.tsx` (light, dark, or system) |
| `--bs-*` variables (body, border, subtle tones, radii) | Worktime-owned `--wt-*` tokens in `src/styles/tokens.css`, same values in both themes |
| Bootstrap reboot | Tailwind preflight (layer `base`) + `src/styles/base.css` |
| `legacy`, `calendar`, `gantt` layers | one `vendor` layer for Schedule-X and Frappe Gantt, below `components` and `utilities` |
| Month calendar SCSS classes (`.is-today`, ...) | `@utility` declarations in `month-calendar.css`; day states are `data-*` attributes |
| CSS-less class hooks (`time-tracking-view`, ...) | `data-slot` attributes |
| `.event-*` classes generated by Sass | plain classes in `event-palette.css`, next to the palette they apply |

## Preflight decision

Tailwind's preflight is enabled, because the shadcn/Base UI components assume it. It differs from
Bootstrap's reboot in ways the app had been relying on, so `base.css` restores them explicitly:
the system font stack, 1.5 line height and body colors, the heading scale and margins, paragraph and
list spacing, link colors, `code`/`kbd`/`pre`/`hr`, inline SVG and images, pointer cursor on buttons,
the browser-default button padding, and Bootstrap's date/time, color-swatch, spin and search input
normalisations. Everything in `base.css` lives in `@layer base`, so any utility still overrides it.

Verification: 13 views (calendar, unified calendar, schedule, transfer, time off table/team/statistics,
time tracking daily/weekly, Gantt chart/table, settings, privacy) were captured before and after in
light and dark at 1280px and 390px, plus the first-run wizard, keyboard shortcuts, calendar legend,
long weekends dialog, day context menu and hover, add-event dialog, label dialog, Gantt dialog and
keyboard focus. The only differences found were the three listed below, all fixed in `base.css`; the
final comparison is pixel-identical apart from a handful of anti-aliasing pixels on the date input.

1. Bare `<button>`s (header brand, accordion trigger) lost the browser's `1px 6px` padding.
2. Native date/time inputs lost reboot's zero padding on their field segments.
3. Color inputs lost reboot's zero padding on `::-webkit-color-swatch-wrapper`.

## Size

Production build (`pnpm build`), same machine, before this change and after:

| | Before | After |
| --- | --- | --- |
| Main CSS (`index-*.css`) | 323.44 kB (46.01 kB gzip) | 98.64 kB (17.32 kB gzip) |
| All CSS chunks | 360.85 kB (53.36 kB gzip) | 136.07 kB (24.68 kB gzip) |
| All JS chunks | 2421.48 kB (717.56 kB gzip) | 2407.30 kB (716.51 kB gzip) |
| PWA precache | 2723.77 KiB | 2490.39 KiB |

The JS gain is small because react-bootstrap was already down to a single (tree-shaken) import; the CSS
saving is Bootstrap's stylesheet. There was no icon font left to drop from the precache (#1383 removed
it earlier).
