# Sync status and Account load failures (#1681)

Generated by `frontend/e2e/sync-status.spec.ts` with mocked authentication and API responses.

Each state has light and dark captures at 1280px and 390px:

- `synced`: successful initial sync.
- `pending`: a local task's push has not settled yet.
- `failed-retrying`: the push returned 503; the automatic countdown is visible.
- `offline`: queued work with the browser offline signal.
- `account-errors`: four failed section loads, one announced banner, four inline retries.
- `recovered`: successful sync and section retries; the outbox is empty and exactly one local task remains.

The browser spec also checks that a failed push never opens a conflict dialog. Unit tests cover real conflicts, content-aware reconciliation and session dismissal. Backup validation is outside this issue.
